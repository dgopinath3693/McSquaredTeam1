## Setup Steps

### Prerequisites
- Docker and Docker Compose installed
- Python 3.8+
- Google Gemini API key (for AiExtractionAgent)

### 1. Clone Repository

```bash
git clone https://github.com/dgopinath3693/McSquaredTeam1.git
cd McSquaredTeam1
```

### 2. Start PostgreSQL Database

```bash
docker compose up -d
```

Database credentials:
- Host: `localhost:5432`
- Database: `mcsq_db`
- User: `mcsq_user`
- Password: `mcsq_pass`

### 3. Install Python Dependencies

```bash

# Core API
pip3 install "fastapi[standard]"
pip3 install fastapi uvicorn[standard] gunicorn

# AiExtractionAgent
pip3 install selenium google-generativeai

# ContentGapAnalysis
pip3 install numpy pandas scikit-learn

# AICrawlerLogging
pip3 install psycopg2 pandas
```

### 4. Configure Environment Variables

```bash
# For AiExtractionAgent
export GEMINI_API_KEY="your_api_key_here"
    # This is free on Google AI Studio

# For AICrawlerLogging
export DATABASE_URL="postgres://mcsq_user:mcsq_pass@localhost:5432/mcsq_db"
```

### 5. Run Components

```bash
# Start FastAPI server
cd FastAPIApp
python3 -m uvicorn main:app --reload --port 8000


# Run gap analysis
python3 ContentGapAnalysis/gapAnalysisImplementation.py \
  --owned-brand "sample_brand" \
  --competitor "sample competitor" \
  --output report.json

# Ingest bot tracking data
python3 AICrawlerLogging/ingest.py \
  AICrawlerLogging/bot_table.csv \
  AICrawlerLogging/server_log.csv
```



# Working Components

**URL_Crawler**: Successfully discovers and crawls URLs from target sites  
**AiExtractionAgent**: Extracts content using Selenium and Gemini API  
**ContentGapAnalysis**: TF-IDF vectorization and cosine similarity calculations work and successfully identifies content gaps between brands 
**Report Generation**: Produces JSON and Markdown reports  
**AICrawlerLogging**: Bot detection and PostgreSQL ingestion functional  
**FastAPIApp**: REST API endpoints operational  
**Database**: PostgreSQL containerization and schema creation  

# Incomplete Components and 

**Rate Limiting**: No rate limiting on crawling 
**Error Recovery**: No retry logic for failed API calls  
**Scalability**: Large datasets will cause memory issues in gap analysis and other analysis components
**Authentication**: No API authentication or SSO no UI
**Real-time Processing**: All processing is batch-based, no streaming  
**ChromeDriver Management**: Manual ChromeDriver installation required  
**Visualization**: No dashboard or visual analytics interface  
**Testing**: Limited testing/no testing pipelines
