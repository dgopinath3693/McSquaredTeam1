# Setup

  ## Database
  Ensure that docker is installed on your machine and currently running, once done a simple command of 

    docker compose up -d

  will get the container up and running on port 5342 as stated in the docker/postgress folder
  
  ## API
  The FASTAPI requires the fastapi package from python downloadable by the following command
    
    pip3 install "fastapi[standard]"

  For production environments please install so all components also get installed along with the framework
  
    pip3 install fastapi uvicorn[standard] gunicorn
